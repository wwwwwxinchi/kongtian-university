# 校园卡活动

前端分支：`activity/campus-card`；后端分支：`activity/campus-card-backend`。活动不合并到常驻官网 `main` / `deploy`。

首页最下方新增「制作校园卡」入口，沿用官网现有字体、蓝色背景、圆角及模块样式。制作页 `/campus-card/` 从本地捏脸工具的多文件版本引入，保留全部 59 份原画部件、男女底图、统一卡背和本科/研究生卡面。没有改变原始素材。

用户下载正面 PNG（1016×638、300 DPI），文件名仍为 `姓名+学号.png`。普通浏览器下载，无需选择目录权限；重复本地下载的覆盖或自动编号由用户浏览器决定。点击「打印」才提交后端；服务器同名直接替换。印刷仍按实际大小 86×54 mm。

管理页 `/campus-card/admin.html` 需登录。可开启或关闭图片接收、按文件名查找、查看最新图片并下载。默认关闭接收，每 20 秒更新制作页状态；服务器每次保存前检查实际状态。

发布仅更新首页、新增活动 CSS 和 `campus-card/` 目录。完整部署步骤与回退方法见后端分支 `backend/campus-card/README.md`。上传图片、账号配置与本地素材源文件不放进前端仓库。
